# Security

Please do not disclose suspected vulnerabilities through a public issue. Use GitHub's **Report a vulnerability** option under this repository's Security tab if it is enabled. If it is unavailable, contact the repository owner privately through an owner-configured contact method before publishing details. The owner should configure a private reporting channel before inviting external security reports.

Never include production tokens, Discord messages, member data, or moderation records in a report unless a private channel has been agreed.

The operator API is designed for loopback access on a trusted machine. It has no remote authentication layer. Do not expose it to the Internet.
